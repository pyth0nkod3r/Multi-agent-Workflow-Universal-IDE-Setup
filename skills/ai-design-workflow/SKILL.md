# AI design workflow

1. Understand the audience, task flow, constraints, and success criteria.
2. Produce a low-fidelity flow or wireframe and obtain user approval before visual exploration.
3. Explore a small number of distinct directions; obtain a direction choice before implementation.
4. Write `DESIGN.md` as the design contract: tokens, type, spacing, component behavior, responsive rules, states, and accessibility requirements.
5. Implement or direct implementation only after the contract is approved. Keep color values in the token layer, validate WCAG AA contrast, and conduct visual QA against the contract.

Do not imitate a competitor's styling or wording. Treat explicit user approval gates as hard stops.
